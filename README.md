# Documentação do ERP (memória do projeto)

Esta pasta funciona como a memória do projeto. Antes de desenvolver qualquer
parte nova do sistema, estes arquivos devem ser consultados. Sempre que o
usuário passar uma regra de negócio importante, ela deve ser registrada no
arquivo correto. Se uma regra mudar, o arquivo deve ser atualizado (não manter
a informação antiga).

## Arquivos

- **00-visao-geral.md** — o que é o projeto, escopo geral (módulos que o ERP
  deve centralizar) e como vamos trabalhar (etapa por etapa).
- **01-regras-de-negocio.md** — todas as regras de negócio explicadas pelo
  usuário, organizadas por módulo (empresas, Mercado Livre, Shopee, pedidos,
  estoque, financeiro, etc.).
- **02-decisoes.md** — decisões importantes tomadas ao longo do projeto,
  em ordem cronológica.
- **03-funcionalidades.md** — partes do sistema que já foram desenvolvidas.
- **04-alteracoes.md** — changelog: alterações importantes feitas no projeto.
- **05-problemas-conhecidos.md** — problemas, limitações ou pendências
  conhecidas que ainda não foram resolvidas.
- **06-proximos-passos.md** — o que vem a seguir no desenvolvimento.
