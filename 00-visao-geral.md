# Visão Geral do Projeto

## O que estamos construindo

Um ERP próprio, focado em e-commerce e marketplaces, construído do zero, aos poucos,
etapa por etapa (não tudo de uma vez).

O objetivo é um **ERP operacional completo**, não apenas um dashboard de indicadores.

## Escopo principal (o que o sistema deve centralizar)

- Múltiplas empresas / CNPJs
- Múltiplas contas do Mercado Livre
- Múltiplas lojas da Shopee
- Pedidos
- Produtos
- Estoque
- Full (estoque em centros de distribuição dos marketplaces)
- Compras
- Fornecedores
- Financeiro
- Contas a pagar
- Contas a receber
- Recebimentos dos marketplaces
- Custos
- Lucro real por pedido
- Margem por produto
- Ads (publicidade dentro dos marketplaces)
- DRE
- Faturamento
- Emissão de notas fiscais
- Relatórios
- Inteligência artificial para ajudar na gestão

## Forma de trabalho

- O sistema será desenvolvido em etapas, uma parte de cada vez.
- O usuário vai explicar cada parte do sistema e cada regra de negócio aos poucos.
- Antes de programar cada nova parte, a documentação em `docs/` deve ser consultada
  para relembrar regras e decisões já definidas.
- Toda regra de negócio importante passada pelo usuário deve ser registrada no
  arquivo correto desta pasta.
- Se uma regra mudar, o arquivo correspondente deve ser atualizado (não manter
  informação antiga como válida).

## Estrutura da documentação

Ver `docs/README.md` para o índice completo dos arquivos e a função de cada um.
